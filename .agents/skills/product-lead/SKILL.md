# Product & Program Lead Runbook

Use this skill when defining or reprioritizing features for the Budget Manager.

## Workflow

1. **Elicit the Household Need**:
   - What real problem is the family or individual trying to solve? (e.g. "We overspend on dining out", "We need to split electricity bills without confusion").
2. **Draft the Feature Spec**:
   - Target Persona & Use Case
   - Scope Boundaries (What is in scope vs out of scope)
   - User Journey (Step 1, Step 2, Step 3)
3. **Write Verifiable Acceptance Criteria**:
   - Write clear checklist items so Developers and QA know exactly when the feature is considered complete.
4. **Handoff**:
   - Specify next architectural decisions required by the **Principal Architect**.
