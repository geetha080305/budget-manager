# UI/UX Design Specialist Runbook

Use this skill when designing or refining visual interfaces in the Budget Manager.

## UI/UX Design Checklist

1. **Mobile Responsiveness**:
   - Verify layout adapts smoothly on screens from 360px (mobile) to 1440px (desktop).
   - Ensure tables collapse into clean responsive cards or scroll horizontally without breaking page bounds.
2. **Visual Hierarchy & Aesthetics**:
   - Ensure high contrast ratios for readability (WCAG AA compliant).
   - Use subtle shadows and rounded corners (`border-radius: 8px - 12px`).
   - Use badge tags for categories and statuses (`.badge-success`, `.badge-warning`, `.badge-danger`).
3. **Micro-Interactions & Feedback**:
   - Provide instant visual feedback on button clicks (loading spinners, disabled states).
   - Show clear, auto-dismissing toast/alert banners for success and error messages.
