# Savings Goals Requirements (REQ-SVG)

## 1. Overview
Empowers users and families to plan and track progress towards financial targets (e.g., Emergency Fund, Vacation, Gadgets).

## 2. Requirements & User Stories
- **REQ-SVG-01 (Define Goal)**: Name goal, target amount, and target completion date.
- **REQ-SVG-02 (Contributions)**: Record incremental deposits toward the goal.
- **REQ-SVG-03 (Progress Calculation)**: Display percentage completed ($\text{current} / \text{target} \times 100$) and remaining funds required.
